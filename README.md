C exercises from the second semester of the Data Structures and Algorithms I course.

## Structure

```
segundo-periodo-aed1/
├── Lab 01 (Introdução a C - variáveis e operadores)   (Intro to C - variables and operators)
├── Lab 02 (condicionais, while, for, do-while, break) (Conditionals, while, for, do-while, break)
├── Lab 03 (laços, condicionais e funções)             (Loops, conditionals and functions)
├── Lab 04                                             (Loops, conditionals and functions)
├── Lab 05 (Vetores e Matrizes)                        (Arrays and Matrices)
├── Lab 06 (alocação dinâmica de memória)               (Dynamic memory allocation)
├── Lab 07 (tipos estruturados)                        (Structured types)
├── Lab 08 (arquivos)                                  (Files)
├── Lab 09 (recursão)                                  (Recursion)
└── Lab 10 (listas)                                    (Linked lists)
```

Each folder holds the `.c` files for one lab, grouped by topic.

## How to run

Compile and run an exercise individually with a C compiler such as GCC:

```bash
cd "segundo-periodo-aed1/Lab 01 (Introdução a C - variáveis e operadores)"
gcc numero.c -o numero
./numero
```
